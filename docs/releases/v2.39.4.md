# Crucix 2.39.4 — egy példány, `irm` telepítő és HTTP parser-abort / single instance, irm installer and HTTP parser abort

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar

- **Standalone telepítő.** Node nélkül: `irm https://github.com/arlinamid/Crucix/releases/latest/download/install.ps1 | iex` (Windows) vagy `curl -fsSL …/install.sh | sh` (Linux/macOS). A script a platform exe-t tölti a Release-ről, SHA-256-ot ellenőriz, és a `%USERPROFILE%\.local\bin` / `~/.local/bin` alá rakja.
- **Egy példány.** A dashboard és a `--collector` `runs/instance.lock`-ot vesz. Ugyanazon a profilon a második folyamat azonnal kilép (`already running`), halott PID-et felülír. Több sweep ne égesse az AIS-t és a napi kvótákat.
- **RSS TLS abort.** Az undici Agent nem tartja életben a socketet egy feed után. A Node `assert(!this.paused)` Parser.finish hibája egyszer figyelmeztet, a folyamat nem áll le.

## 🇬🇧 English

- **Standalone installer.** No Node: `irm https://github.com/arlinamid/Crucix/releases/latest/download/install.ps1 | iex` (Windows) or `curl -fsSL …/install.sh | sh` (Linux/macOS). The script downloads the platform exe from the Release, checks SHA-256, and puts it in `%USERPROFILE%\.local\bin` / `~/.local/bin`.
- **Single instance.** The dashboard and `--collector` take `runs/instance.lock`. A second process on the same profile exits immediately (`already running`); a dead PID is replaced. Extra sweeps must not burn AIS and daily quotas.
- **RSS TLS abort.** The undici Agent does not keep the socket after a feed. Node's `assert(!this.paused)` in Parser.finish is logged once; the process continues.
