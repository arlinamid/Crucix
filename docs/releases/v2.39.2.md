# Crucix 2.39.2 — `crucix --version`, két telepítési út / `crucix --version` and two install paths

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar

- **`crucix --version`** (`-v`, `-V`, `version`) kiírja a csomagverziót. A standalone exe a buildkor beégetett számot adja, az `npm` / git telepítés a `package.json`-t olvassa.
- **Két telepítés:** `npx crucix` / `npm install -g crucix` Node + runtime source. `npm run install:local` a `crucix.exe`-t a `%USERPROFILE%\.local\bin` / `~/.local/bin` mappába teszi. A kettő nem ugyanaz.
- Az npm `2.39.0` és `2.39.1` a registry staged-foglalása miatt nem jelent meg nyilvánosan; ez a patch a következő szabad verzió.

## 🇬🇧 English

- **`crucix --version`** (`-v`, `-V`, `version`) prints the package version. The standalone exe uses the version baked in at build time; an npm or git install reads `package.json`.
- **Two installs:** `npx crucix` / `npm install -g crucix` is Node plus runtime source. `npm run install:local` puts `crucix.exe` in `%USERPROFILE%\.local\bin` / `~/.local/bin`. They are not the same install.
- npm `2.39.0` and `2.39.1` stayed unpublished because the registry reserved them as staged versions; this patch is the next free number.
