# Crucix 2.40.0 — CLI sweep/collector, ACLED-javítás és maszkolt kulcsok / CLI sweep and collector, ACLED fix and masked keys

**Kiadás dátuma / Release Date:** 2026-10-13

---

## 🇭🇺 Magyar

- **CLI.** A `--sweep` és a `--collector` a háttérszerver nélkül is kitölti az előzményeket, a kockázatot, a riasztásokat, a deltát és a sweep-archívumot. Szigorú argumentumkezelés (ismeretlen kapcsoló: hiba, kilépési kód 2), `--port`, az élő országhírek összeomlásának és az előzmények hibáinak javítása. Új e2e tesztcsomag.
- **`--country-risk`.** A rögzített események száma mindig 0 volt: az eseménytár azonosító szerint kulcsolt, a CLI országkód szerint kereste. Most az országban történt (`m: 'l'`) eseményeket számolja.
- **`--live` offline.** A világ-RSS gyorsítótár forrásonként csoportosított, ezért a lista tetején régi, egy forrásból származó hírek álltak. Most idő szerint rendez, a dátum nélküliek a végére kerülnek.
- **ACLED.** Az `acleddata.com` Cloudflare-kihívással utasította el a `User-Agent: Crucix/2.2` fejlécű kéréseket (HTTP 403) a tokenvégponton és az adatvégponton is; az egyéni UA kikerült. Új: `scripts/acled-token.mjs` (e-mail és jelszó bekérése rejtve, tokenek mentése a `.env`-be). A `403 Access denied` az adatlekérésen a fiók jogosultsága (Terms of Use, profil, API-hozzáférés).
- **Beállítás.** BLS, ACLED és OpenSky a varázslóban és a webes oldalon. A varázsló a jelszót és a klienstitkot rejtve kéri, és nem írja ki a mentett értéket. A webes oldalon az API-kulcsok maszkoltak, animált szem ikonnal megjeleníthetők.

## 🇬🇧 English

- **CLI.** `--sweep` and `--collector` fill the history, risk, alerts, delta and the sweep archive without a background server. Strict argument handling (unknown option: error, exit code 2), `--port`, fixes for the live country-news crash and history bugs. A new e2e test suite.
- **`--country-risk`.** The recorded-event count was always 0: the event store is keyed by id while the CLI looked it up by country code. It now counts the events located in the country (`m: 'l'`).
- **`--live` offline.** The world-RSS cache is grouped per feed, so old items from a single source led the list. It is now sorted newest first, undated items last.
- **ACLED.** `acleddata.com` answered requests carrying `User-Agent: Crucix/2.2` with a Cloudflare challenge (HTTP 403) on both the token and the data endpoint; the custom UA is gone. New: `scripts/acled-token.mjs` (asks for the e-mail and a hidden password, saves the tokens to `.env`). A `403 Access denied` on the data call is the account's permission (Terms of Use, profile, API access).
- **Setup.** BLS, ACLED and OpenSky in the wizard and the web page. The wizard asks for the password and client secret hidden and never prints a saved value. On the web page API keys are masked, with an animated eye to reveal them.
