# Crucix 2.38.1 — Platformfüggetlen Binárisok Kiadása, SHA-256 Ellenőrzés és CI Automatizálás / Cross-Platform Standalone Binaries, SHA-256 & Automated CI Releases

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar Összefoglaló (Hungarian)

A Crucix **v2.38.1** karbantartási és kiadási frissítés, amely teljes mértékben automatizálja a platformfüggetlen, önálló futtatható binárisok (SEA) előállítását, ellenőrzését és közzétételét a GitHub Actions CI munkafolyamaton keresztül.

### Főbb Újdonságok és Javítások:

1. **Automata Platformfüggetlen Bináris Kiadás a GitHub Release-ekhez:**
   - A GitHub Actions CI (`.github/workflows/ci.yml`) mostantól minden tagelt kiadás (`v*`) esetén automatikusan lefordítja, ellenőrzi és közzéteszi a standalone binárisokat a kiadás alatt:
     - **Linux x64:** `crucix-linux-x64`
     - **Windows x64:** `crucix-windows-x64.exe`
     - **macOS (Apple Silicon & Intel):** `crucix-macos-arm64`
   - A CI munkafolyamat automatikusan létrehozza a GitHub Release-t (ha még nem létezett) vagy frissíti a már meglévő kiadás mellékleteit (`gh release upload --clobber`).

2. **Kriptográfiai SHA-256 Integritás-ellenőrzés (`SHA256SUMS.txt`):**
   - Minden platform binárisához előáll egy összesített `SHA256SUMS.txt` fájl a kiadás gyökerében.
   - Helyi építéskor a `scripts/build-exe.mjs` automatikusan legenerálja a `.sha256` fájlokat, a `scripts/verify-exe.mjs` pedig szigorúan ellenőrzi az integritást.

3. **Megbízható Build & Verify Folyamat (Felugró ablakok nélkül):**
   - A `build-exe.mjs` mostantól nem csak kiírja a sikert, hanem azonnal leellenőrzi a bináris válaszképességét (smoke test).
   - A `verify-exe.mjs` tesztelése során a `NO_AUTO_OPEN: '1'`, `HEADLESS: '1'` és `--no-open` jelzők meggátolják a fejlesztői böngészőablakok felugrását az automatizált tesztek alatt.
   - A standalone binárisba ágyazott statikus dashboard (`jarvis.html`) és a beállító webszerver (`setup.html`) forrásfájlok nélküli, izolált környezetben is hibátlanul működik.

## 🇬🇧 English Summary (English)

Crucix **v2.38.1** is a release automating multi-platform standalone binary builds (Node SEA), cryptographic verification, and GitHub CI release distribution.

### Key Changes:

1. **Automated Multi-Platform Release Binaries on Git Tags:**
   - The GitHub Actions CI pipeline (`.github/workflows/ci.yml`) compiles, verifies, and packages standalone native executables across the OS matrix on every release tag (`v*`):
     - **Linux x64:** `crucix-linux-x64`
     - **Windows x64:** `crucix-windows-x64.exe`
     - **macOS (Apple Silicon & Intel):** `crucix-macos-arm64`
   - Directly attaches all binaries and unified checksums to the GitHub Release via automated GitHub CLI integration (`gh release create` / `gh release upload`).

2. **Cryptographic SHA-256 Checksums (`SHA256SUMS.txt`):**
   - Produces a single canonical `SHA256SUMS.txt` covering all released binaries for independent integrity verification.
   - Local builds automatically compute and verify SHA-256 hashes in `scripts/build-exe.mjs` and `scripts/verify-exe.mjs`.

3. **Robust Build & Verification Without Window Hijacking:**
   - Immediate post-build verification ensures built executables respond properly before reporting success.
   - Suppresses browser popups (`NO_AUTO_OPEN: '1'`, `HEADLESS: '1'`, and `--no-open`) during automated verification.
   - Self-contained embedded dashboard assets (`jarvis.html`) and setup wizard (`setup.html`) run without requiring local repository files.
