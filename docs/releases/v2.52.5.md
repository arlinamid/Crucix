# Crucix 2.52.5 — Nincs felugró cmd-ablak Cursorral / No pop-up cmd windows with Cursor

**Kiadás dátuma / Release Date:** 2026-11-02

---

## 🇭🇺 Magyar

- **Cursor LLM-szolgáltató (Windows).**
  - A Cursor-szolgáltató `cmd.exe`-n keresztül indítja a `agent` CLI-t. Ezt a hívást eddig úgy indították, hogy a konzolablak látható maradt, így minden hívásnál új cmd-ablak nyílhatott.
  - Az indítás mostantól `windowsHide: true` beállítással fut. A stdin/stdout csövek és a kimenet változatlan.

## 🇬🇧 English

- **Cursor LLM provider (Windows).**
  - The Cursor provider runs the `agent` CLI through `cmd.exe`. That spawn did not hide its console window, so each call could open a new visible cmd window.
  - The spawn now uses `windowsHide: true`. The stdin/stdout pipes and the output are unchanged.
