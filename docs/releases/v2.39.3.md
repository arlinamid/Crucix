# Crucix 2.39.3 — kvóták, RSS-pool és 180 s Cursor-ideas / quotas, RSS pool and 180 s Cursor ideas

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar

- **Napi kvóta.** A 15 perces sweep nem égeti el a napi keretet: OpenSky 429 és az utolsó jó kör a profilcache-ben marad; BLS 12 órát cache-el (v1 ~25/nap, `BLS_API_KEY` = v2 500/nap); ACLED OAuth `scope=authenticated`, 6 órás last-good; EPA 403 után 6 óra szünet; CelesTrak IPv4 + 2 órás cache, Starlink/OneWeb nem minden sweepben; Launch Library frissesség 72 óra a `last_updated` mezőn.
- **RSS.** 8 IPv4-first worker, 12 s / feed, 20 s budget a dashboard listának. Üres világ-sweep nem törli a cache-t; a 539-es runner 45 s-cel a boot után indul, hogy ne ütközzön az első synthesize-szel.
- **Cursor ideas.** Az Agent CLI első byte-ja élőben ~50 s. A default `LLM_IDEAS_TIMEOUT_MS` 180000. Opt-in élő teszt: `CRUCIX_LIVE_LLM=1`.

## 🇬🇧 English

- **Daily quotas.** A 15-minute sweep no longer burns the daily cap: OpenSky persists 429 and the last good round in the profile cache; BLS is cached 12 hours (v1 ~25/day, `BLS_API_KEY` = v2 500/day); ACLED OAuth uses `scope=authenticated` and keeps last-good for 6 hours; EPA skips for 6 hours after 403; CelesTrak uses IPv4 plus a 2-hour cache and does not pull Starlink/OneWeb every sweep; Launch Library freshness is 72 hours on `last_updated`.
- **RSS.** 8 IPv4-first workers, 12 s per feed, 20 s budget for the dashboard list. An empty world sweep keeps the cache; the 539-feed runner starts 45 s after boot so it does not collide with the first synthesize.
- **Cursor ideas.** The Agent CLI's first byte measured ~50 s live. Default `LLM_IDEAS_TIMEOUT_MS` is 180000. Opt-in live test: `CRUCIX_LIVE_LLM=1`.
