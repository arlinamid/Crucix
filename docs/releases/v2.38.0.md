# Crucix 2.38.0 — Önálló Natív Bináris, Interaktív Beállító Varázsló és Globális RSS Katalógus / Standalone Native Executable, Interactive Setup Wizard & Global World RSS

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar Összefoglaló (Hungarian)

A Crucix **v2.38.0** mérföldkő a projekt életében. A rendszer mostantól nemcsak forráskódból futtatható, hanem egy teljesen önálló, zárt natív binárisként (`crucix.exe` / `crucix`) is rendelkezésre áll, valamint beépített interaktív beállító varázslóval segíti az új felhasználók és operátorok azonnali elindulását.

### Főbb Újdonságok:

1. **Interaktív Beállító Varázsló (`crucix setup` / `npm run setup`):**
   - Végigvezeti a felhasználót lépésről lépésre a legfontosabb beállításokon.
   - **Kimeneti nyelv:** Magyar (hu), Angol (en), Francia (fr).
   - **Dashboard & Hálózat:** Port (alapértelmezett: 3117) és helyi hálózati elérhetőség (127.0.0.1 vagy 0.0.0.0).
   - **Mesterséges Intelligencia (AI):** Cursor IDE Zero-config, helyi Ollama, LM Studio/vLLM, Claude, GPT, Gemini vagy kikapcsolt (szabályalapú) mód.
   - **Telegram Riasztások és Kétirányú Bot:** Lépésről lépésre útmutató a `@BotFather` és `@userinfobot` használatával, beépített azonnali tesztüzenettel!
   - **Discord Riasztások:** Webhook beállítása egyszerűen, beépített próbaüzenettel.
   - **Ingyenes OSINT API Kulcsok:** FIRMS, FRED, EIA, AISStream, Cloudflare Radar regisztrációs linkek és beállítás.
   - **Automatikus észlelés:** Ha új gépen argumentumok nélkül indítják el a `crucix`-et és még nincs `.env`, automatikusan elindul a varázsló.

2. **Részletes Beállítási Útmutatók:**
   - [Magyar nyelvű útmutató](docs/SETUP-GUIDE.hu.md) és [Angol nyelvű útmutató](docs/SETUP-GUIDE.md).

3. **Önálló SEA Bináris (`bin/crucix.exe`):**
   - 100%-ban önálló, zárt natív bináris (Node SEA + esbuild), beágyazva tartalmazza az összes forrásmodult, szótárat és geo-adatot.
   - Tiszta felhasználói profil (`%USERPROFILE%\.crucix`): kizárólag a `.env` és `runs/` adatkönyvtárak találhatók benne, a forráskód nem módosítható és nincs kitéve.
   - Telepítő script: `npm run install:local` (vagy `npm run install:local -- --setup`).

4. **Globális World RSS Hírszerzési Katalógus:**
   - 539 ellenőrzött nemzetközi médium 191+ országból.
   - 14 geopolitikai nagyrégió szerinti térképes fókusz és interaktív országválasztó.

## 🇬🇧 English Summary (English)

Crucix **v2.38.0** is a major release introducing fully standalone native binaries, an interactive setup wizard, comprehensive onboarding documentation, and global geopolitical coverage.

### Key Changes:

1. **Interactive Setup Wizard (`crucix setup` / `npm run setup`):**
   - Step-by-step walkthrough in the terminal for `.env` generation and configuration.
   - **Language:** English (en), Hungarian (hu), French (fr).
   - **Dashboard & Network:** Port (default: 3117) and LAN accessibility.
   - **AI/LLM Provider:** Cursor IDE zero-config, local Ollama, LM Studio/vLLM, Claude, GPT, Gemini, or rules-only.
   - **Telegram Alerts & Bot:** Guided walkthrough with `@BotFather` and `@userinfobot` plus instant verification test.
   - **Discord Alerts:** Simple webhook integration with connection test.
   - **Free OSINT API Keys:** Guided input for FIRMS, FRED, EIA, AISStream, Cloudflare Radar.
   - **Zero-config First Run:** Launches wizard automatically if no `.env` exists.

2. **Dedicated Setup Guides:**
   - [English Setup Guide](docs/SETUP-GUIDE.md) and [Hungarian Setup Guide](docs/SETUP-GUIDE.hu.md).

3. **Standalone Production Binary (`bin/crucix.exe` & `bin/crucix`):**
   - Single executable application (SEA) bundling runtime, modules, dictionaries, and geo data.
   - Clean user profile separation (`~/.crucix/.env` and `~/.crucix/runs`), with no raw code tampering.
   - Local installer: `npm run install:local` and `npm run install:local -- --setup`.

4. **Global World RSS Intelligence Catalog:**
   - 539 curated, verified news outlets across 191+ countries.
   - 14 geopolitical map regions and interactive country selector.
