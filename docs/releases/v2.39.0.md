# Crucix 2.39.0 — npm csomag, hírcsatorna-kezelő, bizonyítékos botok és bővített piacok / npm package, news-feed manager, evidence bots and expanded markets

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar Összefoglaló (Hungarian)

A Crucix **v2.39.0** az első nyilvános npm-kiadás: `npx crucix` vagy `npm install -g crucix` telepít, a beállítások és a `feeds.json` a profilba (`%USERPROFILE%\.crucix` / `~/.crucix`, vagy `CRUCIX_HOME`) kerülnek, nem a git checkoutba. A dashboardon a hírcsatornák régió és ország szerint csoportosítva szerkeszthetők, a Telegram- és Discord-riasztások forráslinket visznek, a botok `/ask` és `/risk` parancsot kaptak, a piacok pedig FMP / Finnhub / Yahoo / ECB sorrendben, felhasználói bázisdevizával jelennek meg.

### Főbb újdonságok

1. **npm csomag és profil**
   - `npx crucix` első indításkor a varázslót nyitja; `crucix install` létrehozza a `~/.crucix` profilt (`.env` és `runs/`).
   - A setup oldal és a varázsló a profil `.env` fájljába ír (`CRUCIX_ENV_FILE` vagy `CRUCIX_HOME/.env`). Egy checkout nem ír a projekt `.env`-jébe.
   - A hírcsatorna-felülírások a profil `feeds.json` fájljában élnek.
   - Publikálás: `npm run publish:manual` helyben (tiszta fa, check, teszt, megerősítés), illetve a CI `publish-npm` jobja az `npm` environmenten, provenance-szel, `v*` tagre vagy kézi indításra.

2. **Hírcsatornák a Beállításokban**
   - Be/ki kapcsolás csatornánként vagy egy egész régió/ország csoportjára, saját RSS felvétel, OPML import/export.
   - Az országcsoport a csatorna melletti országnevet kattintva, név szerint választható (nem kétbetűs ISO-kód).
   - A változás a következő sweep-től él.

3. **Telegram- és Discord-riasztások**
   - Szintszűrés csatornánként (`TELEGRAM_ALERT_MIN_TIER` / `DISCORD_ALERT_MIN_TIER`, alapból PRIORITY). Az alacsonyabb szint a `/brief`-ben jelenik meg.
   - Minden riasztás bizonyítékot, forráslinket és egy „miért fontos” sort visz.
   - `/ask` — csak a legutóbbi sweep adataiból, engedélyezett felhasználóknak, 500 tokenes kerettel.
   - `/risk <országkód>`, `/brief [téma]`, `/status`, `/mute`, `/unmute`.

4. **Piacok**
   - Forrás sorrend: FMP (2 batch hívás sweepenként), Finnhub, Yahoo, ECB.
   - Világindexek (DAX, FTSE, Nikkei, Hang Seng, BUX), védelem/energia/chip részvények, FX keresztek.
   - `CRUCIX_BASE_CURRENCY` (alapból USD); a dashboardon lenyíló menüből is váltható.

## 🇬🇧 English Summary (English)

Crucix **v2.39.0** is the first public npm release: `npx crucix` or `npm install -g crucix` installs it, and settings plus `feeds.json` live in the profile (`%USERPROFILE%\.crucix` / `~/.crucix`, or `CRUCIX_HOME`), not in a git checkout. Settings → News feeds edits RSS groups by region and country name. Telegram and Discord alerts carry source links. The bots gain `/ask` and `/risk`. Markets merge FMP, Finnhub, Yahoo and ECB, with a user-chosen base currency.

### Key changes

1. **npm package and profile**
   - `npx crucix` opens the wizard on first run; `crucix install` creates `~/.crucix` (`.env` and `runs/`).
   - The setup page and the wizard write the profile `.env` (`CRUCIX_ENV_FILE` or `CRUCIX_HOME/.env`). A source checkout does not write the project `.env`.
   - Feed overrides live in the profile `feeds.json`.
   - Publishing: `npm run publish:manual` locally (clean tree, check, test, type-the-version), and the CI `publish-npm` job on the `npm` environment with provenance, on a `v*` tag or a manual dispatch.

2. **News feeds in Settings**
   - Switch feeds on or off one by one or by region/country group, add your own RSS, import and export OPML.
   - Move a feed by clicking its country name and picking from a named list (not a two-letter ISO box).
   - Changes apply from the next sweep.

3. **Telegram and Discord alerts**
   - Per-channel minimum tier (`TELEGRAM_ALERT_MIN_TIER` / `DISCORD_ALERT_MIN_TIER`, default PRIORITY). Lower tiers are held for `/brief`.
   - Each alert includes evidence, a source link and a “why it matters” line.
   - `/ask` — latest sweep only, allow-listed users, 500-token budget.
   - `/risk <country>`, `/brief [topic]`, `/status`, `/mute`, `/unmute`.

4. **Markets**
   - Source order: FMP (two batch calls per sweep), Finnhub, Yahoo, ECB.
   - World indexes (DAX, FTSE, Nikkei, Hang Seng, BUX), defense/energy/chip equities, FX crosses.
   - `CRUCIX_BASE_CURRENCY` (default USD); the dashboard dropdown can override it per browser.
