# Crucix 2.39.5 — Linux lock-teszt és Release artifact checkout / Linux lock test and Release artifact checkout

**Kiadás dátuma / Release Date:** 2026-10-11

---

## 🇭🇺 Magyar

A 2.39.4 CI a Linux tesztmátrixon és a bináris csomagoláson elhasalt. A lock-teszt a PID 1-et holtnak vette (az init); a `actions/checkout` a letöltött exe-k után törölte a `dist-raw`-t. Ugyanaz a 2.39.4 viselkedés.

## 🇬🇧 English

2.39.4 CI failed on the Linux test matrix and binary packaging. The lock test treated PID 1 as dead (init); `actions/checkout` after the artifact download wiped `dist-raw`. Same 2.39.4 behavior.
